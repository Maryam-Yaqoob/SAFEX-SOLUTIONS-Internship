# Authorization Note

This project was tested exclusively against a local, self-hosted lab environment
that I built specifically for this task:

- **Lab domain:** `pms-lab.test`, a fake DNS zone using the reserved `.test` TLD
  (RFC 6761), which can never resolve on the real internet.
- **Lab DNS server:** `lab_dns_server.py`, running locally on `127.0.0.1:5353`.
- **Lab HTTP server:** `lab_http_server.py`, running locally on `127.0.0.1:8080`,
  virtual-hosting all lab subdomains by the `Host` header.
- No real third-party service (GitHub, GitHub Pages, Amazon/AWS, Heroku,
  Microsoft Azure, or any other provider) was ever contacted, queried, or
  scanned. All "provider" responses (e.g. the S3 `NoSuchBucket` XML, the
  GitHub Pages "unclaimed site" page, the Heroku 404) are mock pages served
  by my own local HTTP server, modelled on publicly documented error formats.
- The scanner (`subtakeover_scanner.py`) hard-codes an authorization guard:
  any target outside `pms-lab.test` is refused before any DNS or HTTP lookup
  is made (verdict `SKIPPED_UNAUTHORIZED`). `targets.txt` deliberately
  includes `example.com` to demonstrate this guard.

**AI interpretation layer:** the LLM-assisted interpretation step
(`ai_interpreter.py`) sends only short (<=300 character) snippets of HTTP
response bodies generated by my own local lab server to the Google Gemini
free-tier API for interpretation. No real scan data, real domain names, or
data belonging to any third party was ever sent to any AI service. I used
the free tier, which per Google's terms may use submitted data to improve
their models; since all data sent originated from my own synthetic lab,
nothing sensitive or real was exposed.

In short: nothing in this project ever touched a real, production, or
third-party-owned system.
